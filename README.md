# Прогнозирование выработки электроэнергии ветроэлектростанцией

## Описание проекта

В данном проекте представлен инструмент для почасового прогнозирования объёма выработки электроэнергии сетью ветроэлектростанций на основе исторических данных по выработке и прогнозных метеорологических данных.

Инструмент реализован в рамках участия в хакатоне [**«Энергия ветра»**](https://hackathon.thothex.com/hackathon/81?tab=1):

## Предобработка данных

### 1. Восстановление пропущенных временных записей

В исходных данных присутствовали пропущенные строки (отсутствовали данные за отдельные часы).

Для восстановления временной непрерывности были добавлены недостающие записи, а значения признаков вычислены с помощью линейной интерполяции по соседним значениям:

* значение за час до пропуска;
* значение через час после пропуска.

### 2. Заполнение пропущенных значений метеопризнаков

Пропущенные значения наблюдались для следующих признаков:

* `wind_direction_180m`
* `wind_speed_180m`

Для их восстановления использовалась модель линейной регрессии на основе стандартизованных признаков:

#### Для `wind_direction_180m`

* `wind_direction_10m`
* `wind_direction_80m`
* `wind_direction_120m`

#### Для `wind_speed_180m`

* `wind_speed_10m`
* `wind_speed_80m`
* `wind_speed_120m`

### 3. Создание признаков (feature engineering)

| Признак   | Описание |
| --------- | -------- |
| last_{1/4/8/24}h_target_mean | Средний объём выработки энергии за последние 1/4/8/24ч |
| capacity_lt{0.01/0.05/0.1}_time | Кол-во часов подряд с КИУМ менее 1/5/10% с поправкой на кол-во ВЭУ в ремонте |
| time_from_last_capacity_lt{0.01/0.05/0.1} | Кол-во прошедших часов с последнего случая, когда КИУМ был < 1/5/10% с поправкой на кол-во ВЭУ в ремонте |
| target_increasing_time | Кол-во часов подряд, когда объём выработки энергии непрерывно рос |
| target_decreasing_time | Кол-во часов подряд, когда объём выработки энергии непрерывно падал |
| last_hour_momentum | Отношение объёма выработки энергии 1ч назад к объёму выработки 2ч назад ((t-1) / (t-2)) |
| inday_target_to_max_ratio | Отношение выработанной с начала дня энергии к максимальной (если бы КИУМ всегда был 100%) |

## Обучение модели

### Разделение выборки

#### Обучающая + валидационная выборка

* **01.01.2022 — 30.09.2025**

#### Тестовая выборка

* **01.10.2025 — 31.12.2025**

---

## Схема обучения и валидации

### Кросс-валидация

Использовалась схема:

* **5-Fold Cross Validation**
* стратификация по месяцам

Метрика качества:

* **RMSE: 7.389**

### Тестирование модели

Для оценки качества на тестовой выборке использовался подход:

* **Recursive prediction**

Результат:

* **RMSE: 11.813**
